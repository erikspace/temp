Build Central Dashboard
========================

Static first-pass dashboard for use from an SMB/network share.

Open index.html directly in Microsoft Edge. No server or build step is required
for the static mockup.

The dashboard is intentionally focused on individual builds rather than aggregate
CI metrics. The overnight Platform/main build is the primary item, with recent
builds underneath and direct links for logs, artifacts, and build images.

Replace the sample build data and hrefs in index.html with the real build system
paths/URLs when wiring it up.
